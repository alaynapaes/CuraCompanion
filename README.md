# Cura Companion

## Project Overview

Cura Companion is a web-based caregiver support platform designed to assist family caregivers in providing safe, confident, and compassionate home care. The platform offers structured training resources, mental health support tools, and guided assistance to reduce caregiver stress and improve quality of care.

This project focuses on accessible learning, responsive design, and a clean user interface tailored for caregivers.

---

## Key Features

### 1. Responsive Navigation System

- Fixed top navigation bar  
- Mobile-friendly hamburger menu  
- Reusable header and footer loaded dynamically using JavaScript  
- Clean and consistent layout across pages  

---

### 2. Home Page

- Hero section with animated typing effect highlighting core services:
  - Caregiver Support  
  - Medication Management  
  - Real-Time Assistance  
  - Elderly Care Made Easy  
- Feature cards explaining platform benefits  
- Clear call-to-action for video learning  
- Embedded AI chatbot integration  

---

### 3. Video Library

The platform includes categorized caregiver training resources:

#### Medical and Physical Care Training
- Wound Care  
- Pain Management  
- Medication Management  
- Patient Transfer Techniques  
- Healthy Eating  
- Sanitization and Cleaning  
- Drain Care  

#### Emotional and Mental Health Support
- Guided breathing techniques  
- Grounding exercises (5-4-3-2-1 method)  
- Burnout awareness  
- Stress management tools  
- Reflection prompts for caregivers  

Each category uses responsive video cards with embedded YouTube content and hover effects.

---

### 4. Mental Health Support Page

- Quick stress-relief tools  
- Self-reflection prompts  
- Frequently asked questions  
- Emergency contact information (India-specific)  
- Call-to-action for personalized support  

---

### 5. UI/UX Design

- Built with HTML, CSS, and JavaScript  
- Fully responsive layout  
- CSS variables for theme consistency  
- Clean card-based layout  
- Smooth hover and transition effects  
- Google Fonts integration (Figtree)  

---

## Technologies Used

- HTML5  
- CSS3 (Flexbox, Grid, Media Queries, CSS Variables)  
- JavaScript (DOM manipulation, dynamic content loading)  
- Embedded YouTube videos  
- Zapier chatbot integration

## Project Structure

- index.html – Home page  
- videoLib.html – Main video library page  
- training.html – Medical and physical training videos  
- healthSupport.html – Emotional and mental health support  
- header.js – Dynamic header loader and mobile toggle logic  
- footer.js – Dynamic footer loader  
- styles.css – Global styling  
- Media assets (icons, images, backgrounds)

## Purpose of the Project

Cura Companion aims to:

- Empower family caregivers with practical training  
- Provide emotional well-being tools  
- Offer structured, easy-to-understand caregiving resources  
- Make caregiving education accessible and organized  

This project demonstrates responsive frontend development, structured UI design, and modular content loading using JavaScript.
